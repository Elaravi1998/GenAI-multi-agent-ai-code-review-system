# 🕵️ Multi-Agent AI Code Review System

🤖 An advanced AI-powered code review assistant that uses specialized agents to identify potential bugs, security vulnerabilities, maintainability issues, and missing tests.

## ✨ Key Features

- 🐛 **Bug Detection Agent** — identifies potential logic and correctness issues.
- 🛡️ **Security Agent** — flags risky patterns such as dynamic evaluation, shell execution, and possible hard-coded secrets.
- 🧼 **Code Quality Agent** — highlights maintainability issues and potentially unused code.
- 🧪 **Testing Agent** — checks for test coverage signals and recommends missing test cases.
- 🧠 **Multi-Agent Orchestrator** — combines findings and ranks them by severity.
- 📊 **JSON Report** — exports structured findings and recommendations.
- 🔌 **Extensible Architecture** — prepared for LLMs, LangGraph, MCP, and GitHub integration.

## 🧰 Technology Stack

Python • AST Parsing • Regular Expressions • LLMs • LangGraph • GitHub API • MCP

## 🚀 Project Goal

Build an intelligent code review workflow that helps developers review code more consistently while retaining human oversight.

## 🛡️ Responsible AI

AI-generated findings are advisory, not proof of a vulnerability. Validate results using human review, automated tests, and established static-analysis tools.
